# 대라리 167-14 (라온빌) 매도 실행판

부산 기장군 기장읍 대라리 167-14 원룸건물 매도용 실행 문서.
`index.html`은 Artifact로 게시된 페이지의 소스이며, 단독 파일로 브라우저에서 바로 열린다.

## 매물 요약 (소유주 제공 자료 기준)

| 항목 | 값 |
|---|---|
| 소재지 | 부산 기장군 기장읍 대라리 167-14 (라온빌) |
| 준공 | 2015년 |
| 규모 | 지상 5층 · 12룸 (승강기 없음, 계단식) |
| 대지면적 | 205.2㎡ (62.07평) |
| 연면적 | 352.3㎡ (106.57평) |
| 임대 | 보증금 합계 7,900만 / 월세 합계 400만 (12룸 만실 · 공실 0) |
| 융자 | 새마을금고 2억 4,795만 · 연 4.98% · 승계 가능 |
| 매매 희망가 | 9억 8,000만 |
| 감정가 | 10억 2,000만 (새마을금고 대출용 외부공인감정) |

## 계산값

- 연 임대수입 4,800만
- 표면 수익률 5.33% (보증금 제외 실매수 9억 100만 기준)
- 융자 승계 시 실투자 6억 5,305만 · 연 순수입 3,565만 · 수익률 5.46%
- 대지 평당가 1,579만 / 룸당 8,167만
- 감정가 대비 4,000만(3.9%) 낮음
- 참고: 표면 5.5%는 9억 5,200만, 6.0%는 8억 7,900만 지점

## 정정 이력

초기 판단에서 1층 로비 사진의 호실 번호판을 엘리베이터 층 표시로 오독해
"승강기 있음"으로 기재했다. 소유주 확인 결과 **승강기는 없으며 계단식**이다.

## 사진에서 확인된 사양 (조건표에 없던 것)

- 호수 체계가 4층을 건너뛰어 최상층이 601·602 (승강기는 없음)
- 1층 필로티 주차 (사진상 3~4대)
- 개별 가스보일러 — 호실별 난방
- 풀옵션: 에어컨 · 냉장고 · 세탁기 · 붙박이장
- 분리형 구조 — 주방 분리 + 다용도실(발코니)
- 옥상 우레탄 방수 마감 양호
- 공동현관 · 도어락 · CCTV

사진 20장은 `index.html`에 data URI로 내장되어 있다 (원본은 소유주 구글드라이브 `라온빌` 폴더).

## 적정가 판단 (03 섹션)

세 가지 방법이 모두 9억~9억 8천 구간을 지지한다.

| 방법 | 결과 |
|---|---|
| 수익률 역산 | 표면 5.3% → 9억 8,466만 / 5.5% → 9억 5,173만 / 5.8% → 9억 659만 |
| 원가법 | 9억 8천이면 대지 평당 1,019만. 인근 145-8의 2017년 평당 694만을 연 4~5% 환산하면 988~1,077만으로 부합 |
| 룸당 단가 | 9억 8천 → 8,167만/룸 |

- 호가 9억 8,000만 유지 (합리적 상단)
- 실거래 예상 9억 2천~9억 6천, 협상 하한 9억 3천
- 급매 라인 8억 9,000만 (표면 5.9%)

핵심 약점은 가격이 아니라 금리다. 표면 5.33% 대비 승계 대출 금리가
4.98%로 차이가 0.35%p뿐이라 레버리지 유인이 없다. 매수자가 4.0%로
대환하면 5.83%, 3.5%면 6.02%가 되므로 금리 인하 국면에서 가치가
자동으로 올라간다.

담보 감정가는 경매 회수액을 전제로 보수적으로 산정되므로 시세 상한이
아니다. 광고 근거로 삼기에는 약해 전면에 내세우지 않는다.

## 미확정 항목

- 법정 주차대수
- 건축물대장상 용도 (다가구 vs 다세대)

(층수는 지상 5층으로 확정. 엘리베이터는 4층을 건너뛰는 호수 체계라 최상층이 601·602로 표기된다.)
