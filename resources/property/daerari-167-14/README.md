# 대라리 167-14 (라온빌) 매도 실행판

부산 기장군 기장읍 대라리 167-14 원룸건물 매도용 실행 문서.
`index.html`은 Artifact로 게시된 페이지의 소스이며, 단독 파일로 브라우저에서 바로 열린다.

## 계산값

- 연 임대수입 4,800만
- 표면 수익률 5.71% (보증금 제외 실매수 8억 4,000만 기준)
- 자기자금 5억 9,205만 (보증금·융자 전액 승계 가정) · 연 순수입 3,565만 · 수익률 6.02%
- 대지 평당가 1,579만 / 호실당 8,167만
- 감정가 대비 4,000만(3.9%) 낮음
- 참고: 표면 6.0%는 9억 4,000만 지점

## 정정 이력

초기 판단에서 1층 로비 사진의 호실 번호판을 엘리베이터 층 표시로 오독해
"승강기 있음"으로 기재했다. 소유주 확인 결과 **승강기는 없으며 계단식**이다.

## 사진에서 확인된 사양 (조건표에 없던 것)

- 호수 체계가 4층을 건너뛰어 최상층이 601·602 (승강기는 없음)
- 1층 필로티 주차 (사진상 3~4대)
- 개별 가스보일러 — 호실별 난방
- 풀옵션: 에어컨 · 냉장고 · 세탁기 · 붙박이장
- 분리형 구조 — 주방 분리 + 다용도실(발코니)
- 옥상 우레탄 방수 마감 양호
- 공동현관 · 도어락 · CCTV

사진 20장은 `index.html`에 data URI로 내장되어 있다 (원본은 소유주 구글드라이브 `라온빌` 폴더).

## 적정가 판단 (03 섹션)

세 가지 방법이 모두 9억~9억 8천 구간을 지지한다.

| 방법 | 결과 |
|---|---|
| 수익률 역산 | 표면 5.3% → 10억 4,566만 / 5.5% → 10억 1,273만 / 5.8% → 9억 6,759만 / 6.0% → 9억 4,000만 |
| 원가법 | 9억 8천이면 대지 평당 1,019만. 인근 145-8의 2017년 평당 694만을 연 4~5% 환산하면 988~1,077만으로 부합 |
| 호실당 단가 | 9억 8천 → 8,167만/실 |

- 호가 9억 8,000만 유지 (표면 5.71%, 승계 시 6.02%)
- 실거래 예상 9억 5천~9억 8천, 협상 하한 9억 5천
- 조정 하한선 9억 4,000만 (표면 6.0%)

보증금이 1억 4,000만으로 정정되면서 실매수금이 8억 4,000만으로 줄어
표면 수익률이 5.71%가 되었다. 승계 대출 금리 4.98%를 0.73%p 웃돌아
레버리지가 정상 작동한다(5.71% → 6.02%). 금리 4.0%에서 6.43%,
3.5%에서 6.64%까지 오른다.

광고 표현 제약: 소유주 요청에 따라 '급매'·'급급매'는 어떤 채널에도
사용하지 않는다.

담보 감정가는 경매 회수액을 전제로 보수적으로 산정되므로 시세 상한이
아니다. 광고 근거로 삼기에는 약해 전면에 내세우지 않는다.

## 미확정 항목
